## Фазы

| Фаза | Папка | Содержание |
|---|---|---|
| 1. Выбор концепции | `phase1/` | Формирование не менее четырёх концепций и не менее четырёх критериев их оценки; применение трёхточечных экспертных оценок; выбор лучшего варианта с помощью нечёткого коллективного TOPSIS и чёткого коллективного МАИ; сопоставление полученных результатов |
| 2. Распределение работы (мета) | `phase2/` | Разбиение работ третьей фазы на составляющие; экспертное оценивание их сложности; учёт индивидуальных предпочтений исполнителей; формулировка и решение задачи распределения работ |
| 3. Оценка проекта | `phase3/` | Составление не менее десяти Use Cases; оценивание проекта методами COSMIC FP и Use Case Points; проведение коллективной экспертной оценки; выводы о масштабе проекта, численности команды и длительности выполнения |
| 4. Прогнозирование (мета) | `phase4/` | Декомпозиция работ пятой фазы; применение трёхточечных оценок; построение двух моделей Монте-Карло — по количеству задач, выполняемых за неделю, и по трудозатратам; определение срока с достоверностью 80% |
| 5. Планирование | `phase5/` | Формирование перечня из 20–25 задач проекта; описание состава команды через типы ресурсов; задание ресурсных потребностей и связей предшествования; перебор эвристик упорядочения; разработка календарного плана исходя из 40-часовой рабочей недели |
